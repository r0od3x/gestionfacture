# Excel templates

Place the two Excel templates used by the export step here (they are not committed because they
contain client data):

| File | Used by | Default env variable |
|---|---|---|
| `attestation.xlsx` | `export_attestation.py` | `ATTESTATION_TEMPLATE` |
| `calcul.xlsx` | `export_calcul.py` | `CALCUL_TEMPLATE` |

Any other location can be configured in `.env`.
